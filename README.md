# Holonomic Drive Robot Chassis (2012)

This repo is just an archive of an old Arduino project.

Bot was built using VEX Mecanum wheels and motors with Sabertooth motor controllers.
(Never completed the project; stalling the motors by driving into an obstacle made it blow a fuse, and I never got around to implementing current monitoring.)

https://github.com/user-attachments/assets/4a88da5d-358e-4544-8b3d-32cad585940d
